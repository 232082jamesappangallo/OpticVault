  composer install
  cp .env.example .env
  php artisan key:generate
  php artisan migrate --seed
  php artisan serve

Terminal 2 - Frontend:

  flutter pub get

🔧 SETUP TROUBLESHOOTING:

Problem: Backend connection refused
→ Solution: Jalankan "php artisan serve" di terminal backend

Problem: Database error
→ Solution: Update .env dengan database credentials Anda

Problem: Flutter error
→ Solution: flutter clean && flutter pub get

Problem: Login gagal
→ Solution: Jalankan "php artisan db:seed" untuk reset data
